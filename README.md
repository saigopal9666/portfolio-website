## 🚀 FEATURED PRODUCTION ENGINEERING PROJECTS

### 1. ⚡ Enterprise EV Telemetry Data Engineering Platform
* **Stack:** Azure Data Factory, Databricks, PySpark, Delta Lake, ADLS Gen2
* **Description:** 3-Tier Medallion Lakehouse processing **50 Million synthetic EV telemetry records** per day. Features Metadata-Driven ADF Control Tables, idempotent Delta `MERGE INTO` (CDC), Data Quality Quarantine isolation, and Delta **Liquid Clustering (`CLUSTER BY vehicle_id, date`)** achieving **100x query acceleration** for Power BI DirectLake analytics.

### 2. 🤖 Jiddu — Autonomous Voice AI Health Companion
* **Stack:** Vapi SDK, Azure STT, OpenAI GPT-4, ElevenLabs TTS, Make.com, Notion DB
* **Description:** Empathetic, automated Telugu/English Voice AI companion for parents living away from home. Delivers **sub-150ms real-time conversational latency** via WebSockets and automated daily medication/sugar log tracking.

### 3. 🐦 Real-Time Twitter / X Data Pipeline & Sentiment Analytics
* **Stack:** PySpark, Spark Streaming, Delta Lake, Databricks, TextBlob NLP
* **Description:** Real-time Twitter/X API JSON stream ingestion pipeline analyzing public tech trends and Elon Musk tweet engagement. Applies PySpark Window functions (`ROW_NUMBER()`, `AVG()`) to compute real-time sentiment polarity scores.

### 4. 💻 Interactive SQL to PySpark & Delta Code Translation Engine
* **Stack:** JavaScript AST Parsing, PySpark DataFrames, Delta Lake DDL
* **Description:** Interactive web application converting complex ANSI SQL queries (`GROUP BY`, `HAVING`, `DENSE_RANK`) into production-ready PySpark DataFrame transformations and Delta Lake optimization code.
